## 🤝 How to Contribute

All our repos are open for contributions. Here is how to get involved:

1. ⭐ **Star repos** you find useful — it helps others discover them
2. 🐛 **Open Issues** for bugs, corrections, or project ideas
3. 🔀 **Submit PRs** — improvements to guides, new project ideas, bug fixes
4. 💬 **Vote on upcoming projects** — open an Issue with the project you want built next

Each repo has a `CONTRIBUTING.md` with specific guidelines.
